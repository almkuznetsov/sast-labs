## Часть 2. Python, JavaScript SCA
Аналогичные `go.mod` списки зависимостей часто есть в проектах на python и javascript. В ходе этой части познакомимся с двумя инструментами генерации SBOM для проектов на этих языках, а также попробуем отредактировать SBOM и проанализировать, как это отразится на сработках.

В ходе выполнения заданий 2 части у нас должны получиться следующие артефакты работы:
- скриншоты выполнения пунктов задания.
- файлы bom.json для обоих приложений.
- фрагменты bom.json с описанием разбираемых сработок, пример их исправления.

### Python SCA
Сгенерируйте SBOM для проекта superset (https://github.com/apache/superset) используя `cyclonedx-py` и опираясь на один из списков зависимостей в requirements. Запустите анализ полученного SBOM с помощью trivy, разберите одну любую сработку:
- В каком пакете уязвимость?
- Как выглядит запись об этом пакете в `bom.json`? По какому идентификатору (PURL/CPE) анализатор определяет актуальность уязвимости? Что будет, если в этом идентификаторе изменить версию на версию с исправлением?
- Измените bom.json так, чтобы сработка перестала появляться при анализе trivy.
